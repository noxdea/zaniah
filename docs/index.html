A window is ordinary Ruby

The UI layer is opt-in. Use core elements alone, or load the component library when the application needs it.

  • Component reference
  • Animation
  • Accessibility
  • Terminal behavior
  • Themes
require "zaniah/ui"

app = Zaniah::App.new
app.open_window(backend: :mac) do
  Zaniah::UI::Button.new("Save")
    .icon(:check)
    .on_click { save }
end
app.run
