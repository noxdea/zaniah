画面をつくる。

01 / INSTALL

まずは 1 gem。

CRuby 3.1 以降が必要です。Gemfile に追加し、Bundler でインストールします。UI コンポーネントは zaniah/ui を読み込むと利用できます。

Gemfile
gem "zaniah"
Terminal
bundle install

まず試したい場合 Ruby コードだけで PNG を生成できる :headless から始めると、ディスプレイや GPU の設定は不要です。

02 / FIRST FRAME

最初の 1 枚を描く。

ウィンドウを開き、draw に要素ツリーを渡します。tick で 1 フレーム描画して PNG に保存します。

hello.rb
require "zaniah"

window = Zaniah::Platform.open_window(
  backend: :headless, width: 480, height: 240
)
window.text_system = Zaniah::TextSystem::Renderer.new
window.draw do
  Zaniah::Div.new.flex_col.p(24).gap(12).bg("#161b22")
    .child(Zaniah::Text.new("Hello, Ruby", size: 24))
    .child(Zaniah::Text.new("A native toolkit, written in Ruby."))
end
window.tick
window.write_png("hello.png")
window.close
Terminal
bundle exec ruby hello.rb

実行すると作業ディレクトリに hello.png ができます。これはテストで画面を比較するときにも使える描画方法です。

03 / INTERACTIVE

同じ考え方で、ウィンドウへ。

zaniah/ui を読み込めば、ボタンや入力などのコンポーネントを要素と同じツリーに配置できます。ネイティブアプリでは tick の代わりに run でイベントループを開始します。

window.rb · macOS の例
require "zaniah/ui"

window = Zaniah::Platform.open_window(
  backend: :mac, width: 640, height: 360, title: "Hello Zaniah"
)
window.draw do
  Zaniah::Div.new.flex_col.p(24).gap(16)
    .child(Zaniah::UI::Label.new("Hello, Zaniah", size: :xl))
    .child(Zaniah::UI::Button.new("Save", variant: :primary)
      .icon(:check).on_click { puts "Saved" })
end
window.run

Linux なら :linux、Windows なら :windows に変更します。ネイティブ環境の前提条件は Native backends を参照してください。

04 / COMPOSITION

要素を並べ、ふるまいを渡す。

01

レイアウト

Div に flex_col、gap、p などを指定し、child で子を追加します。

02

コンポーネント

UI::Button、UI::TextField、UI::Table などを同じツリーに置けます。

03

イベント

on_click や on_change にブロックを渡します。状態が変わったら必要に応じて再描画します。

テーマ、キーボード操作、アクセシビリティもコンポーネント層に含まれます。使い分けや画像は コンポーネント図鑑 にまとめています。

05 / BACKENDS

描画先を選ぶ。

backend使いどころ出力
:macmacOS アプリMetal / OpenGL
:linuxLinux デスクトップWayland / X11
:windowsWindows アプリWin32 / WGL
:headless画像生成・自動テストPNG / ピクセル
:tuiターミナルANSI セル

ターミナルでは一部の見た目をテキストに置き換えます。対応の詳細は Terminal UI を参照してください。
