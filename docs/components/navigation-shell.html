Toolbar, sidebar, and status bar

Build application chrome from horizontal tools, vertical navigation, and compact status.

Import

Load the optional component layer before using the examples below.

Ruby
require "zaniah/ui"

Application chrome

Each container accepts children. Sidebar also accepts a width.

Ruby
Zaniah::UI::Toolbar.new(
  Zaniah::UI::Button.new("New"),
  Zaniah::UI::Button.new("Edit"))
Zaniah::UI::Sidebar.new(
  Zaniah::UI::Label.new("Files"), width: 180)
Zaniah::UI::StatusBar.new(Zaniah::UI::Label.new("Ready"))

API summary

Constructor options and behaviors are drawn from the component reference.

ComponentConstructor and methodsVariants or behavior
Toolbar(*children), childhorizontal
StatusBar(*children), childhorizontal
Sidebar(*children, width:), childvertical
