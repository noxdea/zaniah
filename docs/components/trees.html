Docs/Data and visualization

Tree view

Navigate nested data such as files, projects, and settings categories.

Import

Load the optional component layer before using the examples below.

Ruby
require "zaniah/ui"

Nested items

Items have stable IDs, labels, and children. A lazy children proc loads once on first expansion.

Ruby
items = [{id: :src, label: "src", children: [
  {id: :main, label: "main.rb"},
  {id: :lib, label: "lib", children: []}
]}]
Zaniah::UI::TreeView.new(items, height: 240)

Replace lazy children

Call replace_children(id, children) on the UI thread when asynchronous loading completes; call invalidate(id) to reload.

Ruby
tree.replace_children(:lib, [{id: :ui, label: "ui.rb"}])
